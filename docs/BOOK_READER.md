# 책 뷰어·진입 화면 복귀 명세 (2026-09-17, v2)

## 책의 순서

1. 첫 화면: 왼쪽은 비우고 오른쪽에 앞표지·제목·표지 그림을 둔다.
2. 데스크톱: 장면 첫 펼침의 왼쪽에 삽화 한 장, 오른쪽에 해당 장면의 첫 본문을 둔다.
3. 이어지는 펼침: 양쪽 모두 본문이다. 삽화는 반복하지 않는다. 새 장면은 새 펼침에서 시작한다.
4. 장면의 마지막 본문 쪽이 홀수면 반대쪽은 빈 종이다. 다른 장면을 억지로 섞지 않는다.
5. 마지막 본문을 넘기면 왼쪽 뒷표지, 오른쪽 완료 안내와 버튼이 나온다.
6. 퀴즈가 있는 신규 동화는 '문제 풀러 가기', 읽기 전용/퀴즈 없는 동화는 '돌아가기'다.

모바일은 같은 순서의 종이를 한 쪽씩 표시한다. 장면 삽화 한 쪽 다음에 본문 쪽들이 이어진다.
끝 화면에서는 작은 뒷표지와 완료 안내를 상하로 배치한다.

## 크기와 조작

- 사이트 헤더 64px 아래 전체 높이를 쓴다. 펼친 책의 가로:세로는 1.42:1이며 한 쪽은 0.71:1인 세로형이다.
- 컨테이너의 실제 너비와 높이를 모두 고려해 책 크기를 정한다. 작은 높이에서는 최소 읽기 높이를 보장해 세로 스크롤을 허용한다.
- 컨트롤은 왼쪽 사이드 리모컨에 모았다: 이전 화면, 이전/다음 장, 현재 위치, 글자 크기, 처음부터, 전체 화면.
- 종이 클릭/가로 드래그/방향키 이동을 지원한다. Home/End는 앞/뒷표지다. 마지막 화면의 실제 버튼은 페이지 넘김과 구분한다.
- 620ms 종이 앞뒤 회전 애니메이션을 유지한다. 감소된 모션 설정에서는 즉시 이동한다.
- 회전하는 복제면은 aria-hidden과 inert로 감춰 화면 읽기/키보드 초점에 중복으로 나타나지 않는다.

## 페이징과 데이터 흐름

`API pages[] → useReadingPages(실제 종이의 본문 영역 측정) → paginateStory(원문 분할)
→ buildBookSpreads(표지/삽화/본문/빈 종이/뒷표지 배치) → PopupBook`

- 표지를 보고 있을 때도 숨은 본문 종이로 정확한 높이를 측정한다.
- 글꼴·크기·화면 변화 뒤 sceneIndex/startOffset/endOffset으로 읽던 위치를 찾는다. 앞/뒷표지를 보고 있었다면 표지를 유지한다.
- 글꼴 알림이 와도 분할 결과가 같으면 배열을 재생성하지 않아 진행 중인 넘김을 불필요하게 취소하지 않는다.
- 원문/공백/개행과 장면 이미지 URL은 변경하지 않는다. 그림은 object-fit:contain으로 전체 표시한다.
- 새 유료 이미지 생성은 없다. 표지 URL이 없는 과거 동화는 첫 장면 이미지를 표지에만 폴백한다.

## 돌아갈 화면

| 진입 경로 | 책 리모컨의 이전으로 / 최종 단계 완료 |
|---|---|
| 대시보드에서 생성 동화 열기 | 대시보드 홈 뷰 |
| 생성 동화 퀴즈 결과 화면의 이전으로 | 대시보드 홈 뷰 |
| 라이브러리에서 저장 동화 열기 | 라이브러리 목록(보기 방식 유지) |
| 공개 전래동화 열기 | 랜딩 페이지의 전래동화 목록 /#library |

브라우저 history.back()을 이용하지 않고 명시적인 콜백/경로를 쓴다. 완료한 퀴즈나 로그인 화면으로 잘못 돌아가지 않게 하기 위함이다.
보관함 재열람은 기존 정책대로 읽기 전용이며, 퀴즈 재채점 기능을 새로 추가하지 않았다.
퀴즈 진행 중 '동화 다시 보기'는 유지한다. 최종 결과의 이전으로는 퀴즈로 돌아가지 않는다.

## Storage

이미지는 기존 `covers/{story_id}/cover.jpg`, `covers/{story_id}/page-N.jpg` 경로를 계속 쓴다(확장자는 형식에 따라 다름).
서버 pages[]는 장면 단위이고 화면의 종이 수와 다르다. 장면별 URL과 저장 방식, API 스키마는 변경하지 않았다.

## 검증

- 순수 배치 테스트: 표지/뒷표지 위치, 장면당 삽화 1회, 이어지는 양면 본문, 원문 보존, 그림 없는 동화, 크기 변경 후 읽기 위치.
- 기존 페이징·생성 상태 테스트 및 TypeScript 검사.
- 브라우저: 1440×900 데스크톱, 390×844 모바일에서 표지→삽화→본문→뒷표지, 버튼/키보드 이동과 완료 콜백 확인.

## 최종 회귀 검증

- 프론트 production build, 별도 TypeScript 검사, book-layout/story-pagination/generation-controller 테스트 통과.
- 백엔드 unittest 97개 통과. 기존 동화 프롬프트 파일의 정확 일치 검사도 통과했다.
- 실제 브라우저 1440×900/390×844에서 표지, 장면 첫 삽화, 본문 전용 이어지는 쪽, 뒷표지, 글자 확대, 클릭/키보드/드래그, 퀴즈 있음/없음 완료 콜백 확인.
- 모바일 재측정 중 이동 취소를 보완했다. 넘김 목적지를 먼저 기억하여 화면 재분배 후에도 요청한 위치를 유지한다.
- 로그인한 운영 계정의 전체 흐름은 실행하지 않았다. 상위 화면 복귀는 컴포넌트 콜백과 dashboard/library 연결 코드를 확인했다.
- 검증용 페이지와 임시 이미지는 배포 대상에서 제거했다. DB 및 환경변수 추가 작업은 없다.
