# 동화책 뷰어 구현 명세 (2026-09-17)

## 화면과 조작

- `PopupBook`은 생성 직후, 보관함에서 다시 읽기, 공개 전래동화 읽기에 공통 사용한다.
- 데스크톱(768px 이상)은 왼쪽에 삽화/장면 제목, 오른쪽에 본문을 배치한다.
- 모바일은 위에 삽화, 아래에 본문을 배치한다. 그림 클릭은 이전, 본문 클릭은 다음이다.
- `object-fit: contain`으로 삽화 전체를 표시한다. 원본 비율에 따른 여백은 정상이며 그림을 자르지 않는다.
- 본문은 Next Font의 고운바탕 400을 쓴다. 글자 크기 조절과 전체 화면 읽기를 제공한다.
- 본문의 서버 줄바꿈을 보존한다. 화면을 채우려고 원문을 요약/삭제하거나 장면을 섞지 않는다.
- 페이지 클릭, 이전/다음 버튼, 마우스·터치 가로 드래그, 방향키로 이동한다. Home/End는 처음/마지막이다.
- 가로 이동 45px 이상이며 세로 이동보다 1.3배 커야 스와이프로 처리한다. 세로 스크롤은 유지한다.
- 책장 앞뒤 면을 620ms 동안 책등 축으로 회전한다. 모바일은 한 장을 회전시킨다.
- 애니메이션 중 추가 이동은 무시하고, 크기 변경 시 이전 애니메이션/타이머를 취소한다.
- `prefers-reduced-motion` 사용자는 애니메이션 없이 바로 이동한다. 자동 페이지 넘김은 없다.
- 마지막 장의 '다 읽었어요'는 기존 onFinish를 호출한다. 퀴즈 이동 등 기존 흐름은 유지한다.

## 화면에 맞춘 페이징

`use-reading-pages.ts`는 본문 영역의 실제 너비/높이를 ResizeObserver로 읽는다.
본문과 동일한 CSS를 쓰는 숨은 문단에 원문을 넣어, 들어갈 수 있는 분량을 측정한다.
`story-pagination.ts`가 문장/어절 경계를 우선해 분할하며, 긴 단어는 유니코드 글자 단위로 나눈다.
폰트 로딩 완료, 글자 크기 변경, 창 크기 변경, 전체 화면 전환 때 다시 계산한다.
분할 결과는 sceneIndex/startOffset/endOffset을 가지고 있어 화면 변화 후 읽던 원문 위치를 찾는다.
아주 작은 높이에서는 읽을 수 있는 최소 책 높이를 유지해 세로 스크롤을 허용한다.
예외적인 글꼴이나 긴 글자에서도 본문 영역은 스크롤할 수 있어 원문을 숨기지 않는다.

## 이미지와 서버 계약

API `pages[]`는 원본 장면이다. 뷰어의 '펼침'은 화면 크기에 따라 늘어날 수 있다.
같은 장면이 여러 펼침으로 나뉘면 같은 이미지 URL을 그대로 쓰고 '같은 장면의 이야기'를 표시한다.
이미지는 서버에서 추가 생성하지 않으며 프론트가 임의로 다른 장면/표지 이미지를 대신 붙이지 않는다.
이미지 없음/생성 실패/HTTP 이미지 오류는 각각 안내와 종이 배경으로 대체한다. 본문은 계속 읽을 수 있다.
API의 page_number, image, image_status, heading, text 형식은 변경하지 않았다.

## Storage에서 찾는 위치

현재 생성 파이프라인은 별도 pages 버킷 대신 기존 **covers 버킷**을 사용한다.

```text
Storage → covers → story_<동화 ID>/
  cover.jpg            # 표지 (형식에 따라 png/webp 가능)
  page-1.jpg           # 첫 장면
  page-2.jpg
  ...
```

`generation/providers.py:upload_image()`가 `covers/{story_id}/{name}.{확장자}`에 업로드한다.
`generation/graph.py`는 병렬 완료 순서가 아니라 page_number로 대응시켜 각 pages[].image에 URL을 넣는다.
공개 URL 형식은 `/storage/v1/object/public/covers/{story_id}/page-N.jpg`다.
캐릭터 시트는 후속 이미지 생성을 위한 메모리 참조용이며 현재 Storage에 별도 보관하지 않는다.
컷별 이미지 옵션을 끈 동화는 표지만 생성하고 pages[].image는 비어 있다.

## 검증

- TypeScript 타입 검사와 기존 페이징 테스트: 원문/공백/개행 보존, 이모지, 긴 단어, 장면 이미지 유지, 리사이즈 읽기 위치.
- 실제 브라우저: 1440×900 데스크톱, 390×844 모바일에서 본문 넘침 및 가로 넘침 확인.
- 모든 테스트 펼침 이동, 이미지 대응, 페이지 클릭/드래그/키보드 End, 글자 확대 후 장면 유지, 읽기 완료 콜백 확인.
- 이미지 없음 및 실패 시 대체 안내, 전체 화면 버튼 전환 확인.
- 운영 최신 이미지 포함 동화는 5개 장면, 서로 다른 컷 URL 5개, Storage 객체 5개 모두 HTTP 200 확인.
- 개인정보 없는 임시 동화로 UI를 검증했다. 새 유료 이미지/동화 생성 호출은 하지 않았다.
