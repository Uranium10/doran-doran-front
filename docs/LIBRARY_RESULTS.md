# 라이브러리 목록 / 결과 격려 태그 / 문제 기록

2026-09-18 구현. 스티커북은 별도 `STICKER_BOOK_DESIGN.md`의 설계 단계다.

## 목록형 책장

- `library-gallery.tsx`에서 목록/그리드의 그림을 분리했다. 그리드는 기존 `BookCover`, 목록은 `LibraryThumbnail`을 사용한다.
- 목록 왼쪽 6px 테두리에 `normalizeCoverColor()`로 검증된 표지색을 적용한다. 없는/잘못된 색은 기존 갈색이다.
- 데스크톱 썸네일 88×68px, 모바일 64×64px. `object-fit:cover`로 비율을 유지하며 필요할 때만 가장자리를 자른다. 이미지가 없거나 실패하면 색 배경과 아이콘을 보여준다.
- 긴 제목은 두 줄로 제한한다. 그림 자체에는 책 제목/입체 책 모형을 중복 렌더링하지 않는다.
- 모의 브라우저 실측 목록 행 높이: 데스크톱 94px, 모바일 110px. 모바일 버튼은 아이콘으로 줄이되 각각 44px 터치 영역과 접근 가능한 이름을 유지한다.

## 책별 문제 기록

- 그리드와 목록 모두 삭제 버튼 옆에 같은 위계의 ‘문제 기록’ 버튼을 배치했다.
- 누른 책에 대해서만 기존 `GET /api/v1/quiz-results?profile_id=...&story_id=...`를 조회한다. 모든 책의 기록을 미리 가져오지 않는다.
- 기존 API는 최근 순으로 반환하며 현재 페이지네이션이 없다. 기록을 아주 많이 허용하는 재도전 기능 도입 시 서버 페이지네이션/요약 응답을 추가하는 것이 후속 과제다.
- 모달에는 날짜, 총 문항/정답 수, 답안 링크를 표시한다. 로딩/빈 기록/실패 후 재시도 제공.
- 결과 링크는 `/results/{id}?from=library`. 결과지의 돌아가기는 전체 책장으로 연결되며 기존 목록/그리드 설정을 유지한다.
- native dialog의 키보드 초점 제한/Escape를 사용한다. 닫으면 원래 버튼으로 초점을 돌린다. 닫기/책·프로필 전환 시 AbortController로 응답을 취소한다.
- 조회만 사용하므로 문제 회차 생성, 채점, 점수 변경, 삭제 요청은 발생하지 않는다.

## 결과지 격려 태그

카드 윗 경계에 종이색 태그를 겹쳐 놓았다. 그림자와 작은 기울기로 책 위에 얹힌 느낌을 주며, 위쪽 공간을 확보해 제목/점수 영역을 가리지 않는다.

| 정답률 | 문구 |
|---|---|
| 100% | 전부 맞았어요! |
| 70% 이상 | 훌륭해요! |
| 40% 이상 | 더 잘할 수 있어요! |
| 40% 미만 | 괜찮아요, 함께 배워 가요! |

정답이 없는 관찰형 설문(`checklist`), 점수를 숨긴 결과, 총 문항이 없는 결과에는 붙이지 않는다. 점수와 진척도 계산은 변경하지 않았다.

## 검증 및 배포

- TypeScript 검사와 프로덕션 빌드 통과.
- Playwright PC/모바일: 색 테두리, 책 모형 제거, 이미지 비율/실패 대체, 낮은 행 높이, 그리드 유지, 가로 넘침 없음 확인.
- 문제 기록 온디맨드 조회, 빈 목록, 오류/재시도, Escape/포커스 복원, 결과 이동/라이브러리 복귀 확인. API 쓰기는 기존 로그인 동기화 외 0건.
- 네 가지 격려 문구 및 checklist에서 숨김 확인. 페이지 오류 0건.
- 유료 이미지/LLM 호출 없음. API 요청/응답 형식 변경 없음. DB/백엔드/환경변수 작업 없이 프론트만 배포한다.
