# 책 상태 태그·미열람 동화 카드·속지 단면 (2026-09-18)

## 표시 규칙

| 서버 reading_status | 표지 태그 | 판정 |
|---|---|---|
| new | 새 동화 · 빨강/흰 글씨 | 읽기 기록과 해당 동화 채점 결과 모두 없음 |
| reading | 읽는 중 · 파랑/흰 글씨 | 읽기 기록은 있으나 완독 전 |
| quiz_pending | 퀴즈 푸는 중 · 초록/흰 글씨 | 완독했고 저장된 퀴즈가 있으나 채점 결과 없음 |
| completed | 태그 없음 | 채점 완료 또는 퀴즈 없는 동화 완독 |

과거 채점 결과가 있으면 읽기 기록이 없어도 새 책으로 표시하지 않는다. 다시 표지로 돌아간 책도 읽기 기록을 지우지 않으므로 새 책이 되지 않는다. 아직 표지만 열어 본 책은 실제 장 넘김 전에는 새 동화다.

공유 BookCover에 태그를 적용하여 대시보드·라이브러리 표지 보기·목록 보기가 같은 상태를 표시한다. 작은 목록 표지에서는 태그를 줄인다. 태그는 absolute여서 책 크기/제목 위치가 바뀌지 않는다.

## 생성 완료 카드

- 현재 작업이 queued/running이면 기존 종이인형극 및 서버 stage 문구를 표시한다.
- 그 외에는 현재 프로필의 `latest_unread`가 있을 때만 완료 카드를 표시한다.
- `latest_unread`는 현재 페이지에 있는 7권/12권만 확인하지 않고, 해당 아이의 전체 책장에서 생성일 내림차순으로 찾는다. 동률이면 story_id 내림차순이다.
- 카드 제목과 읽기 링크는 그 책을 가리킨다. 오래된 completed job의 result를 다시 열지 않는다.
- 미열람 책도 생성 중 작업도 없으면 카드와 여백을 제거한다. 생성 페이지의 기존 실패 안내는 유지한다.
- 별도 '나중에 읽기'로 카드만 감추는 동작은 제거했다. 읽기 시작 후 다음 미열람 책이 있다면 그 책으로 갱신하고, 없으면 숨긴다.

## 저장 지연과 재조회

읽기 위치 PUT 성공 후 `doran-reading-saved` 이벤트(profileId만 포함)를 발생시킨다. 책장에서 해당 프로필일 때 가벼운 목록을 재조회한다. 책장을 먼저 열고 이전 화면의 마지막 저장이 늦게 도착하는 순서도 처리한다. 대시보드는 창 포커스/탭 재진입/작업 ID·상태 변경에도 새로 조회한다. 늦은 목록 응답은 요청 순번으로 버린다.
