# 모바일 완독 화면 높이 보정 (2026-09-18)

## 원인

모바일 .closedBack이 뒷표지/완독 안내에 높이를 32%/68%로 고정 배분했다.
반면 안내에는 제목·설명·문제·복귀·어휘분석·다시 읽기 동작이 들어간다.
작은 뷰포트에서는 justify-content:center로 묶인 내용이 배정 높이를 초과하고,
종이의 overflow:hidden 때문에 위아래가 잘렸다.

## 수정

- 모바일 뒷표지를 56~80px의 짧은 마무리 장식으로 축소하고 나머지를 안내에 배정.
- 완독 안내는 위에서부터 배치하고 자체 높이를 허용. 공간이 부족하면 endPaper만 세로 스크롤.
- ending에는 native pan-y를 허용하고 책 넘김 pointer capture에서 제외. 텍스트 확대 시에도 마지막 동작에 접근 가능.
- 완독 안내에 접근성 이름 부여. 분석 링크·돌아가기·다시 읽기 동작 유지.
- 페이지 번호를 입력해 이동하면 모바일 입력칸의 포커스 해제. 키보드가 남거나 화면이 입력칸을 따라 움직이는 상황을 줄임.
- 리모컨·본문 측정 영역·일반 페이지 넘김 크기와 데스크톱 좌우 배치는 유지.

## 검증

TypeScript, production build 통과.
Playwright 합성 동화: 390×650, 320×568, 360×580, 412×740, 767×600, 1440×900.
완독 제목의 위쪽 잘림 없음, 모바일 리모컨 겹침 없음, 마지막 버튼까지 접근 가능,
가로 넘침 없음, 페이지 이동 후 모바일 포커스 해제 확인.
40px 확대 제목과 CDP 실제 touchStart/touchMove/touchEnd로 내부 스크롤 확인.
퀴즈 없는 동화의 돌아가기, 퀴즈 있는 화면의 버튼 표시 확인. 브라우저 오류 0.

실제 Samsung Internet 기기 원격 제어는 하지 않았으며, 보고된 문제에 해당하는 작은 뷰포트와 터치를 브라우저에서 재현했다.
API·DB·환경변수 변경 없음. 프론트만 배포한다.
